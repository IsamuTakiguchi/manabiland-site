Privacy Policy

Niko Niko Manabi Land Studio ・ Effective date: 2026-10-17

1. Who we are

Niko Niko Manabi Land Studio (“the Tool”) is a private production tool operated by an individual, Isamu Takiguchi (“the Operator”). The Tool is used only by the Operator to manage the Operator's own YouTube channel “にこにこ まなびランド”. It is not offered to the public.

2. YouTube API Services

The Tool uses YouTube API Services. By using the Tool, its user is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Information the Tool accesses

With the Operator's authorization (OAuth 2.0, scope https://www.googleapis.com/auth/youtube), the Tool accesses only the Operator's own YouTube channel in order to:

  • upload videos as private, and set their titles, descriptions, tags, thumbnails and “made for kids” and altered-or-synthetic-content declarations;
  • change a video's privacy status or scheduled publish time after the Operator approves it;
  • create the channel's playlists and add the channel's videos to them;
  • read the channel name and the public statistics (such as view counts) of the channel's own videos.

The Tool does not access any other user's account, and it does not collect information about viewers. The channel's videos are designated as made for kids, so comments are disabled and the Tool never collects personal information from children.

4. How the information is used, stored and shared

  • Storage. Video IDs, titles, publish schedules and view counts of the Operator's own videos are stored in the Operator's private source-code repository. The OAuth client secret and refresh token are stored as encrypted secrets in the Operator's private GitHub repository and are never published.
  • Freshness. Statistics are refreshed each time the Tool runs, and any statistic that has not been refreshed within 30 days is deleted.
  • Sharing. To plan future episodes, the titles and view counts of the Operator's own videos are sent to Anthropic's Claude API, which processes them on the Operator's behalf. No YouTube API data is sold or shared with anyone else. The Tool also uses the OpenAI API and Google's Gemini API to create illustrations, voices and animation; they do not receive YouTube API data.
  • No cookies. This website and the Tool do not use cookies or similar tracking technologies, and they do not show advertising.

5. Revoking access and deleting data

Access granted to the Tool can be revoked at any time on the Google security settings page (Third-party apps with account access). After access is revoked, or upon request to the contact address below, the Operator deletes the stored YouTube API data described above within 7 days.

6. Changes and contact

If this policy changes, the updated version and its effective date will be posted on this page. Questions and requests: GitHub Issues

プライバシーポリシー

にこにこ まなびランド 制作ツール ・ 施行日：2026-10-17

1. 運営者

にこにこ まなびランド 制作ツール（以下「本ツール」）は、Isamu Takiguchi（以下「運営者」）が個人で運営する制作ツールです。本ツールは、運営者が自分のYouTubeチャンネル「にこにこ まなびランド」を管理するためだけに使用し、一般には提供していません。

2. YouTube API サービスの使用

本ツールは YouTube API サービスを使用しています。本ツールの利用者は YouTube 利用規約に拘束されます。Google によるデータの取り扱いは Google プライバシーポリシーをご覧ください。

3. 本ツールがアクセスする情報

運営者の許可（OAuth 2.0、スコープ https://www.googleapis.com/auth/youtube）に基づき、本ツールは運営者自身のチャンネルにのみアクセスし、次のことを行います。

  • 動画を非公開でアップロードし、タイトル・説明・タグ・サムネイル・「子ども向け」と「改変・合成コンテンツ」の申告を設定する
  • 運営者が承認した動画の公開設定または予約公開日時を変更する
  • チャンネルの再生リストを作成し、チャンネルの動画を追加する
  • チャンネル名と、チャンネル自身の動画の公開統計（再生回数など）を読み取る

他の利用者のアカウントにはアクセスせず、視聴者の情報も収集しません。動画は「子ども向け」として申告しており、コメントは無効になるため、本ツールが子どもの個人情報を収集することはありません。

4. 情報の利用・保存・共有

  • 保存：運営者自身の動画の動画ID・タイトル・公開予定・再生回数を、運営者の非公開リポジトリに保存します。OAuth のクライアントシークレットとリフレッシュトークンは、運営者の非公開 GitHub リポジトリに暗号化して保存し、公開しません。
  • 更新：統計は本ツールの実行のたびに更新し、30日以内に更新されなかった統計は削除します。
  • 共有：今後の企画のため、運営者自身の動画のタイトルと再生回数を Anthropic 社の Claude API に送り、運営者のために処理させます。それ以外に YouTube API のデータを販売・共有することはありません。挿絵・音声・動きの作成には OpenAI API と Google の Gemini API を使いますが、これらに YouTube API のデータは送りません。
  • Cookie：このWebサイトと本ツールは Cookie などの追跡技術を使用せず、広告も表示しません。

5. 許可の取り消しとデータの削除

本ツールへの許可は、Google のセキュリティ設定ページ（アカウントにアクセスできるサードパーティ製アプリ）からいつでも取り消せます。許可の取り消し後、または下記連絡先への依頼を受けてから7日以内に、上記で保存している YouTube API のデータを削除します。

6. 改定と連絡先

本ポリシーを改定した場合は、改定後の内容と施行日をこのページに掲載します。お問い合わせ：GitHub Issues
